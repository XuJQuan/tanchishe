贪吃蛇 · 下载

同一套 Flutter 源码，为六个平台各生成一个原生安装包，外加一个 Web 在线版。 把构建产物按下方文件名放入 releases/ 目录后，对应按钮即可直接下载。

🤖

安卓 Android

APK · arm64-v8a
flutter build apk
下载 APK
🍎

iOS

IPA · 需 macOS + 签名
flutter build ios --release
只能在 macOS 上用 Xcode 构建并签名
下载 IPA
🌸

鸿蒙 HarmonyOS NEXT

HAP · 需 DevEco Studio
DevEco 签名打包（OpenHarmony Flutter 工具链）
官方 stable 的 flutter create 不含 ohos 壳，需 OHOS 工具链生成
下载 HAP
🖥️

Windows

安装包 · x64
flutter build windows
下载 zip
🐧

Linux

tar.gz · x64
flutter build linux
下载 tar.gz
🍏

macOS

DMG · 需 macOS 签名
flutter build macos
下载 DMG
🌐

Web 在线版

浏览器直接玩 · 无需安装
flutter build web
构建后把 snake/build/web 作为静态服务根目录打开，如 python -m http.server 8766 --directory build\web（或 flutter run -d chrome）
在线试玩
各平台构建命令与工具链安装步骤：docs/cross-platform.md
